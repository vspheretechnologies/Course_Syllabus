### 🧠 Red Hat Linux Administration & Server Management Syllabus

| Module | Topic | Description | Lab Exercise |
|--------|-------|-------------|--------------|
| **1** | Introduction to Linux & RHEL | Overview of Linux OS, RHEL editions, installation methods | Install RHEL on VirtualBox/VMware, explore CLI and GUI |
| **2** | Basic Command Line Skills | File system navigation, file manipulation, text processing | Use `ls`, `cd`, `cp`, `mv`, `rm`, `cat`, `grep`, `find`, `cut`, `awk` |
| **3** | User & Group Management | Create, modify, delete users and groups; permissions | Add users/groups, set passwords, configure sudo access |
| **4** | File System Management | Partitions, mounting, LVM, quotas | Create partitions, mount file systems, configure LVM and quotas |
| **5** | Package Management | YUM/DNF, RPM, repositories | Install, update, remove packages; configure local repo |
| **6** | Process & Service Management | Manage processes, systemd services, runlevels | Use `ps`, `top`, `kill`, `systemctl`, enable/disable services |
| **7** | Networking Fundamentals | IP configuration, hostname, DNS, firewall | Configure static IP, test connectivity, manage `firewalld` |
| **8** | Storage & Disk Management | Disk partitioning, formatting, mounting, NFS/SMB | Create partitions, mount NFS share, configure Samba server |
| **9** | Security & SELinux | File permissions, ACLs, SELinux modes | Set ACLs, switch SELinux modes, troubleshoot access issues |
| **10** | Scheduled Jobs & Automation | Cron, at, systemd timers, shell scripting | Schedule cron jobs, write basic shell scripts |
| **11** | Logging & Monitoring | System logs, journalctl, logrotate, performance tools | Analyze logs, configure log rotation, monitor with `vmstat`, `iostat` |
| **12** | Kernel & Boot Management | GRUB, kernel parameters, boot targets | Modify GRUB config, change default kernel, troubleshoot boot issues |
| **13** | Server Administration: Apache | Install and configure Apache web server | Host a static website, configure virtual hosts, enable SSL |
| **14** | Server Administration: MariaDB | Install and manage MariaDB server | Create databases, users, assign privileges, backup/restore |
| **15** | Server Administration: FTP & SSH | Configure secure file transfer and remote access | Set up vsftpd, configure SSH keys, restrict SSH access |
| **16** | Server Administration: DNS & DHCP | Configure name resolution and IP assignment | Set up BIND DNS server, configure DHCP server |
| **17** | Server Administration: Mail & Proxy | Configure mail and proxy services | Set up Postfix mail server, configure Squid proxy |
| **18** | Virtualization & Containers | KVM, libvirt, Podman, Docker basics | Create VMs with `virt-manager`, run containers with Podman |
| **19** | Backup & Recovery | Backup strategies, tools, disaster recovery | Use `tar`, `rsync`, configure automated backups |
| **20** | Final Capstone Project | Design and deploy a multi-service Linux server | Students architect and deploy a full-stack server with web, DB, and security layers |
