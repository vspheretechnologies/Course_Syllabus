# ** Docker training syllabus** 


---

| **S. No** | **Topic**                                      | **Duration (Hours)** | **Details**                                                                                 |
|-----------|------------------------------------------------|-----------------------|---------------------------------------------------------------------------------------------|
| **Day1**     | **Introduction to Docker**                    | 1.0                   | - What is Docker? <br> - Benefits of Containerization <br> - Containers vs Virtual Machines  |
| **Day2**     | **Docker Architecture**                       | 0.5                   | - Key Components: Docker Engine, Images, Containers, Volumes, Networks                     |
| **Day3**     | **Installing Docker**                         | 0.5                   | - Installation on Linux/Windows/Mac <br> - Setting Up a Docker Environment                 |
| **Day4**     | **Docker Images**                             | 1.0                   | - Understanding Images and Layers <br> - Pulling, Inspecting, and Tagging Images <br> - Building Custom Images Using Dockerfile |
| **Day5**     | **Docker Containers**                         | 1.5                   | - Creating and Managing Containers <br> - Running Interactive vs Detached Containers <br> - Stopping, Restarting, and Removing Containers |
| **Day6**     | **Volumes and Persistent Storage**            | 1.0                   | - Understanding Docker Volumes <br> - Creating and Using Volumes for Persistent Data       |
| **Day7**     | **Networking in Docker**                      | 1.0                   | - Docker Network Modes: Bridge, Host, None <br> - Exposing Ports <br> - Connecting Multiple Containers Using User-Defined Networks |
| **Day8**     | **Docker Compose**                            | 1.0                   | - Introduction to Docker Compose <br> - Writing `docker-compose.yml` Files <br> - Managing Multi-Container Applications |
| **Day9**     | **Docker Best Practices**                     | 0.5                   | - Image Optimization Tips <br> - Security Considerations <br> - Managing Resources with Limits |
| **Day10**    | **Hands-On Project**                          | 1.0                   | - Deploy a Multi-Container Web Application Using Docker Compose                            |

---

### **Key Highlights:**
- **Total Duration:** 8 Hours  
- **Training Format:** Theory (40%) + Hands-On Labs (60%)  
- **Prerequisites:** Basic knowledge of Linux commands and an understanding of virtualization concepts (optional).
