

## 🧠 MERN Stack Development – 12 Week Day-Wise Syllabus

### 📅 Week 1: Web Fundamentals & JavaScript Basics

| Day | Topic | Lab Exercise |
|-----|-------|--------------|
| 1 | HTML Structure & Tags | Build a personal homepage with header, footer, and sections |
| 2 | CSS Styling & Layout | Style your homepage using Flexbox and media queries |
| 3 | JavaScript Syntax & Variables | Create a script to calculate age from birth year |
| 4 | Data Types & Operators | Build a BMI calculator with conditional output |
| 5 | Control Flow (`if`, `else`, `switch`) | Create a grade evaluator based on score input |
| 6 | Loops (`for`, `while`) | Generate multiplication tables dynamically |
| 7 | Functions & Scope | Build a reusable tip calculator function |
