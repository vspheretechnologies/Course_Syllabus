
### 🧠 AZ-104 Training Syllabus with Lab Exercises

| Module | Topic | Description | Lab Exercise |
|--------|-------|-------------|--------------|
| 1 | Introduction to Azure | Overview of Azure services, regions, subscriptions, and resource groups | Create an Azure free account, explore Azure Portal, create a resource group |
| 2 | Manage Azure Subscriptions and Resources | Role-based access control (RBAC), policies, tagging, cost management | Assign roles to users, apply tags, set up budgets |
| 3 | Implement and Manage Storage | Blob, File, Queue, Table storage; access tiers; lifecycle management | Create a storage account, upload blobs, configure lifecycle rules |
| 4 | Configure and Manage Virtual Networks | VNet, subnets, NSGs, service endpoints, private endpoints | Create a VNet with subnets, configure NSGs, test connectivity |
| 5 | Manage Azure Compute Resources | VMs, availability sets, scale sets, custom images | Deploy a VM, configure availability set, create a scale set |
| 6 | Implement and Manage Identity | Azure AD, users, groups, roles, conditional access | Create users and groups, assign roles, configure conditional access |
| 7 | Monitor and Back Up Azure Resources | Azure Monitor, Log Analytics, alerts, backup, recovery vault | Set up monitoring for a VM, create alerts, configure backup |
| 8 | Configure Load Balancing and Network Security | Load balancer, Application Gateway, Azure Firewall, VPN Gateway | Deploy a load balancer, configure firewall rules, set up VPN |
| 9 | Manage Azure Governance | Azure Policy, Blueprints, resource locks | Create and assign policies, deploy a blueprint, apply locks |
| 10 | Manage Data Protection | Backup, recovery, replication, shared access signatures | Configure backup for VMs, test restore, use SAS for blob access |
| 11 | Manage Azure Resources Using ARM Templates | Deploy resources using templates, parameter files | Deploy a VM using ARM template, modify parameters |
| 12 | Automate Azure Tasks | Azure CLI, PowerShell, Cloud Shell | Create resources using CLI and PowerShell, automate VM deployment |
| 13 | Implement Azure App Services | Web apps, deployment slots, scaling, diagnostics | Deploy a web app, configure deployment slot, enable diagnostics |
| 14 | Secure Azure Resources | Key Vault, managed identities, security center | Store secrets in Key Vault, assign managed identity, review security recommendations |
| 15 | Final Review and Practice Exam | Recap of all modules, mock exam, Q&A | Take a full-length practice test, review incorrect answers |

### 🧩 AZ-104 Scenarios with Real Time projects

| Module | Scenario | Problem Statement | Solution & Lab Outcome |
|--------|----------|-------------------|-------------------------|
| **1. Azure Fundamentals** | A startup wants to host its services in Azure but has no cloud experience. | How do you set up a secure and scalable Azure environment from scratch? | Create Azure account, configure subscriptions, resource groups, and explore Azure Portal. Students understand Azure's core structure. |
| **2. Manage Subscriptions & Resources** | The startup needs to manage costs and access across departments. | How do you control access and monitor spending across multiple teams? | Implement RBAC, tags, policies, and budgets. Students learn governance and cost control. |
| **3. Implement Storage Solutions** | The dev team needs scalable storage for app data and logs. | How do you design storage that supports blob, file, and lifecycle management? | Create storage accounts, containers, file shares, and configure lifecycle rules. Students understand storage tiers and access. |
| **4. Configure Virtual Networks** | The app must securely communicate across services and regions. | How do you design a secure, segmented network architecture? | Create VNets, subnets, NSGs, service endpoints, and test connectivity. Students learn network isolation and security. |
| **5. Manage Compute Resources** | The app backend requires scalable compute with high availability. | How do you deploy and manage VMs with redundancy and scaling? | Deploy VMs, configure availability sets, scale sets, and custom images. Students understand compute provisioning. |
| **6. Implement Identity Solutions** | The company wants centralized identity management and secure access. | How do you integrate Azure AD and enforce access policies? | Create users/groups, assign roles, configure conditional access. Students learn identity governance. |
| **7. Monitor & Back Up Resources** | The CTO wants proactive monitoring and disaster recovery. | How do you monitor performance and ensure backup readiness? | Set up Azure Monitor, alerts, Log Analytics, Recovery Vault. Students learn observability and resilience. |
| **8. Load Balancing & Network Security** | The app needs high availability and secure external access. | How do you design load balancing and firewall protection? | Deploy Load Balancer, Application Gateway, Azure Firewall, VPN Gateway. Students learn traffic distribution and perimeter security. |
| **9. Azure Governance** | Compliance requires resource control and audit readiness. | How do you enforce policies and prevent unauthorized changes? | Apply Azure Policy, Blueprints, and resource locks. Students learn compliance enforcement. |
| **10. Data Protection** | Sensitive data must be securely stored and recoverable. | How do you protect data from loss and unauthorized access? | Configure backup, replication, and SAS tokens. Students learn data security and recovery. |
| **11. ARM Templates** | The dev team wants repeatable infrastructure deployment. | How do you automate resource provisioning using templates? | Deploy resources using ARM templates and parameter files. Students learn Infrastructure as Code. |
| **12. Automation with CLI & PowerShell** | Admins want to automate routine tasks. | How do you script and automate Azure operations? | Use Azure CLI, PowerShell, and Cloud Shell to manage resources. Students learn automation and scripting. |
| **13. Azure App Services** | The company wants to host a web app with zero downtime. | How do you deploy and manage scalable web apps? | Deploy web app, configure deployment slots, enable diagnostics. Students learn PaaS deployment. |
| **14. Secure Azure Resources** | The app handles sensitive customer data. | How do you secure secrets and enforce least privilege? | Use Key Vault, managed identities, and Security Center. Students learn secure design principles. |
| **15. Capstone Architecture Lab** | The company wants a production-ready architecture for its SaaS platform. | How do you design a complete Azure solution with scalability, security, and resilience? | Students design and deploy a full-stack architecture using all modules. They present and defend their design. |
